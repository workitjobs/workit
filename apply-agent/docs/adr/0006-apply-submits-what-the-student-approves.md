# Apply submits what the student approves

The Apply window's rehearsals never submitted, which left the student to check every live page and press Submit by hand. Now each Hold is a Review card, and its Approve and submit makes Apply press Submit itself. The student can still open the page and submit it by hand. Apply calls a form submitted only once the job system's confirmation page or email shows. Anything less becomes a Handoff that says it may not have gone in, and Apply never submits a form a second time.

Auto-submit, which needs no approval, is an opt-in policy, in a Developer checkout first. It waits ten minutes, with a Cancel in the notification and the window. Only an Application that passed the Pre-submit check with no flags, no Essay and no reason to Hold can go. These never can: a Target company, a form that asks for an emailed code or a captcha, one Apply made an Employer account for in this run, and one on a job system Apply has never submitted to. Submitting everything with no review was rejected. A wrong answer sent to an employer can't be taken back, and the Pre-submit review, now run on the Best model, is the last check before it goes.
